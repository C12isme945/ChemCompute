# 从桌面完成一次计算

安装包包含解释器、Tk 桌面界面及控制端/节点依赖。无需 pip、Python 或浏览器插件。v0.3.0 安装页默认勾选 WSL、GROMACS 和匹配的显示驱动，可取消；桌面“依赖安装”页也可检测、安装和查看状态。主控电脑仅调度时不必安装 GROMACS。依赖下载需要联网，可能要求管理员权限及重启。

首次安装选 Both，打开自动创建的桌面快捷方式，再点击启动后台。远程部署时选对应角色，通过 Tailscale 联网，在桌面生成单次邀请码。更换本机角色或主控监听地址仍需编辑配置文件或重新配置，桌面提供配置目录入口。可选网络安装脚本位于安装目录 scripts。

## 示例计算包

将 `examples/water-smoke/` 中的文件直接放在 ZIP 根目录，不要多套一层目录。发行版同时附带 `ChemCompute-Water-Smoke.zip`。上传后会读取清单，自动填入预处理和计算步骤；预览、按需选择节点或请求 AI 建议，再提交。此示例是两个水分子的 100 步 CPU 冒烟检查，不证明任何科研体系的物理有效性。

计算包可不提供清单：上传后选择模板或追加步骤。文件路径相对包根目录，不能引用节点任意目录；GROMACS 自身安装的力场资源仍可按正常规则读取。交互式 energy/genion 必须另行准备适用的非交互参数，本版不提供交互 stdin。

```json
{"name":"My calculation","steps":[{"subcommand":"grompp","arguments":["-f","run.mdp","-c","conf.gro","-p","topol.top","-o","run.tpr"]},{"subcommand":"mdrun","arguments":["-s","run.tpr","-deffnm","run","-nt","1"]}]}
```

单步还受节点 `config/node.yaml` 中 `max_job_timeout_seconds` 限制（默认 3600 秒），提交端设置更大时限不会越过节点上限。CPU/内存/CUDA 选项用于筛选节点；不会自动替换 `-nt` 等参数。一个任务的多步在同一节点同一独立目录顺序执行。多个独立副本可分别提交，系统依次匹配可用节点。AI 是节点选择助手，不判断科学参数是否正确。

## 结果与故障

任务中心显示排队、运行、完成、失败、已取消，以及步骤进度。结果完成后下载 ZIP 并校验 SHA-256。中途失败或取消时，已生成文件留在执行节点的 `data/workspace/task-…/files`；详情显示失败日志。输入传输、结果传输或网络故障不会被标记为成功。结果上限约 100 MiB，不支持生产级大轨迹流式归档。

失联任务进入恢复状态，仍归原节点所有；节点重连会恢复上报和结果传输。代理重启后，仅有可用检查点的 GROMACS mdrun 支持续算；Gaussian、中断的预处理或缺少检查点时需要人工检查。不会把失联任务直接复制到另一台电脑执行。不要删除节点文件或修改数据库来启动重复任务。原生进程取消会终止子进程树，WSL 取消等待当前步骤退出，超时使用 GNU timeout。

## Gaussian 与多机协作

在节点设置中选择已授权安装的 g16/g09 可执行文件。提交页选择 Gaussian，上传含 `.gjf` 或 `.com` 的 ZIP，使用 `run input.gjf` 步骤。安装包不附带商业软件或许可证；软件探测成功不代表许可证和实际计算已验证。

提交页可设置 1–128 个独立副本，由多个在线节点分配执行。副本使用相同输入；需要不同随机种子或科学参数时，应分别准备计算包。此功能不提供跨互联网的单任务 MPI/Linda 并行。远程节点可使用 `https://chemcompute.666945726.xyz` 和桌面生成的一次性邀请码加入。

## 密钥与升级

DeepSeek 设置只存于当前账号的 DPAPI 文件；复制安装包到其他电脑不会复制密钥。旧版升级保留运行目录，先停止正在执行的计算与旧后台。当前版本未签名，仍为预发布；尚未做另一台无 Python 实机验收，发布验证使用剔除 Python PATH/PYTHONHOME/PYTHONPATH 的打包运行环境。
