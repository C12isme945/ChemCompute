# v0.5.0 界面与升级验收

采用用户提供的浅蓝视觉参考，保留原生 Tk 桌面和全部七页功能。新增侧栏导航、圆角算力卡片、分子装饰、原图标和服务器插画。小窗口中的较宽表单保留水平/垂直滚动。Windows 原生控件不等同于参考图中的毛玻璃渲染。

Gaussian 页面提供已有安装的 Gaussian 09W、GaussView 与工具目录入口，基于本机配置的 g09.exe / g16.exe 路径定位，不捆绑商业软件。formchk/cubegen 仍由用户在工具目录中使用，未新增远程任意命令执行。

- 144 项自动测试通过，1 项按平台跳过。
- 七个导航页面在 1180×780 下实际渲染，页签路由与底部操作可用。
- 打包程序桌面启动、重复启动、状态、关闭、重启、停止检查通过。
- 更新助手处理 GUI 在进程检查之间退出的情况，保持 PID、创建时间、路径与参数校验。

原始插画来自本次用户附件，未修改源图；展示缩放由 Tk 完成。状态和算力来自实时心跳，插画不代表节点已连接。实际 Gaussian 运算和许可证尚未验证。

实际隔离安装 0.4.0 → 0.5.0 已通过：助手安装、重启、接口鉴权、配置字节一致及结果文件保留。
