# 2026-09-12 compatibility repair

The follow-up implementation at `bd97377` replaced the installed v0.3 runtime while keeping its desktop API calls. This repair restores the authenticated runtime contract from `073ad90` before adding UI and update functionality incrementally. The superseded implementation remains available in Git history; design images are retained under `docs/images`.

## Findings and repair

- The replacement API exposed job submission, input/result downloads, progress writes, invite administration and release publication without authentication. Those alternate routes are removed from the active package. Existing authenticated v1/v2 APIs are restored.
- Replacement `nodes` and `jobs` tables reused existing table names with incompatible columns and did not migrate the installed schema. The original database implementation and configuration-driven app factory are restored. No live database is changed by this source repair.
- Desktop package/task/batch and invitation calls targeted routes deleted by the replacement controller. The original routes, data models and regression tests are restored together.
- Gaussian configuration and the built-in execution route were lost. The original Gaussian adapter, software telemetry and configuration contract remain active. Real Gaussian execution still requires a licensed local installation.
- The replacement worker discarded existing task directories, lacked durable result retry/checkpoint recovery, and blocked heartbeats while calculating. The tested durable worker and ownership-preserving leases are restored. Existing node credentials continue to use their original configuration.
- The replacement desktop entrypoint stopped starting the configured Cloudflare tunnel. Original configured-tunnel startup is restored.
- Incompatible alternate installers, worker/plugin/update runtime modules, scripts and their tests are removed from the active tree; they remain in commit history for selective future reuse. Unauthenticated remote Python plugin replacement is not enabled.
- Blocking lint, original package/install smoke checks, and the release rule that preserves already-published assets are restored.

## Verification scope

`tests/test_upgrade_contract.py` guards authenticated management routes, absence of the incompatible public administration routes, Gaussian configuration roundtrip and reopening an existing runtime database without losing invites. Existing package, Gaussian, DeepSeek, lease/reconnect and desktop tests are retained. Test results for this preparation commit are reported separately; this document does not claim a live deployment or a new published release.
