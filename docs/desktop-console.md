# 桌面操控台 · v0.1.1

安装后自动创建桌面 `ChemCompute Console` 快捷方式及开始菜单入口。双击打开原生桌面窗口，无需额外安装 Python；安装完成页面默认提供打开操控台选项。

功能：启动、停止、重启本机后台；分别显示后台进程和主控连接状态；展示节点 CPU、RAM、GPU、GROMACS 信息；打开 Web 控制台、配置目录和日志目录；由用户主动点击复制本机管理员密钥。纯节点角色不会读取远程主控管理员密钥。

关闭窗口后，后台继续运行。停止或重启后台前应确认没有需要继续的计算。旧版 0.1.0 没有新版进程身份记录，升级前应先退出旧程序；不会仅凭进程名称终止未知实例。

## 本机验证（2026-09-11）

- 20 项自动化测试通过，Ruff 通过。
- 原生 Tk 窗口组件、数据渲染、事件循环和退出通过打包程序检查；此检查采用隐藏窗口，不等同于人工视觉验收。
- 打包后台：启动、重复启动不新增实例、状态查询、窗口关闭后继续运行、重启、停止通过。
- 隔离安装：桌面快捷方式自动创建，目标指向操控台启动器，安装后 EXE 注册和心跳通过。
- 卸载：程序及测试快捷方式移除，运行配置保留。
- 测试使用独立安装标识及目录；未停止用户正在运行的 0.1.0 实例。

现有计算限制仍见 README：非原生 Windows Service，尚无自动输入/结果传输及可靠长任务恢复。
