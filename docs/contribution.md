# 在桌面端调节算力贡献

打开左侧 **算力贡献**，选择预设或拖动 CPU / 内存滑块，设置 GPU 开关和暂停接单，然后点击 **保存算力设置**。新电脑与升级后的默认值均为 CPU 50%、内存 50%、GPU 关闭、允许接单；已有节点需要升级到 1.0 才能使用本机控制。

- CPU 是可贡献的逻辑核心数量，向上取整。例如 12 个逻辑核心的 25% 为 3 个核心。不是“总 CPU 占用严格不超过 25%”的时间限流器。
- 原生 GROMACS / Gaussian 通过进程亲和性限制计算和已出现的子进程。无法设置时终止本次任务并报告失败。GROMACS 禁止重新绑定核心的 `-pin on/auto`，使用 `-pin off`；超额线程参数被拒绝。
- WSL GROMACS 使用 **Linux 内部**的 `taskset` 和线程环境变量，不以 Windows `wsl.exe` 的亲和性冒充 Linux 限制。需发行版支持 `taskset`；无法执行则任务失败。本版选择 Linux `0..N-1`，自定义 cpuset 或多处理器组机器需单独验收。
- 内存是 **任务准入预算，不是操作系统内存硬限制**。调度器同时检查节点最近上报的可用内存；程序实际占用可能不同。Gaussian 显式 `%Mem` 超预算会被拒绝，但其额外开销及默认内存不受此预算硬限制。
- GPU 关闭时不接 GPU 请求，GROMACS MD 强制 CPU 后端并隐藏 GPU；Gaussian 的显式 GPU 指令被拒绝。开启表示允许使用，不代表驱动、软件 GPU 支持或许可证已验证。
- Gaussian 不改写科学输入；超额 `%NProcShared`、显式 `%CPU` 核心绑定、Linda 跨机指令等会被拒绝，需用户调整输入。跨机协作通过分配独立任务实现。

保存仅影响 **下一项任务**。正在运行的多步骤任务保存预算快照，断线补传或恢复时沿用该快照。暂停接单不取消已接收任务，恢复与结果补传仍会进行。当前控制是合作节点资源分配工具，不是用于运行不可信原生程序的沙箱。

设置位于 `config/contribution.json`，与 `node.yaml` 分开原子写入，不覆盖注册令牌。设置文件损坏时暂停接单。主控可能在下一次心跳前仍显示旧预算；任务接收后还会用本机快照复核，超预算则失败并保留原因，避免未经允许运行。

调度采用资源预算，硬件上报中的物理核心、内存总量及瞬时占用率保持原意。纯主控机器保存设置不会自动启用计算节点。

参考：[GROMACS mdrun 参数](https://manual.gromacs.org/current/onlinehelp/gmx-mdrun.html)。
