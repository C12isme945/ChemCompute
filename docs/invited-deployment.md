# 专属邀请部署与 Gaussian 安装服务

## 主控电脑

1. 打开“节点与邀请码”，设定有效小时和备注，点击“导出专属邀请部署包”。
2. 确认远程可访问的 HTTPS 主控地址，例如 `https://chemcompute.666945726.xyz`。
3. 保存 ZIP，只发给一台受邀电脑。每台电脑导出一个包。不要把含邀请码的包放到公开仓库。

程序从官方 GitHub 发布获取并校验 ChemCompute 安装器，再创建一次性邀请码。包内没有管理员密钥或长期节点密钥。邀请码过期、撤销或被使用后需重新导出。

## 受邀电脑

1. **完整解压 ZIP**，保持安装器与 `chemcompute-join.ini` 在同一文件夹。
2. 双击安装器，确认加入的主控地址。计算节点角色、地址和邀请码已经预填。
3. 保留“登录时启动”选项，完成安装。后台自动启动、注册并上报心跳；桌面显示连接状态。

以后由主控上传计算包、指定此节点或自动匹配，节点自动执行并回传结果，无需逐次确认。关闭桌面窗口不会停止后台；点击“停止后台”可以暂停参与。电脑需要保持联网、已登录且不休眠。当前是登录启动，不是登录前 Windows Service。

WSL、驱动或厂商安装器可能要求管理员确认和重启。安装不自动接受系统授权。已有 ChemCompute 配置的电脑不自动覆盖入网信息，应在桌面节点页更改。

## Gaussian / GaussView

在主控“依赖安装”页面选择现有的正式 EXE 安装介质。确认目标电脑有安装许可后，可以勾选“导出时附带介质”。介质只进入本地导出的 ZIP，**不上传公开 GitHub**。

受邀安装器仅在发现相邻介质时显示 Gaussian/GaussView 安装选项，默认不选。选中后打开厂商原安装向导。也可在桌面“依赖安装”页选择并启动 EXE/MSI 安装程序。不会自动填写许可证或猜测静默安装参数。

Gaussian 安装在常见的 `C:\G09W`、`C:\G16W` 或 Program Files 下同名目录时会自动探测。其他目录可在后台停止后点击“定位已安装 g09.exe / g16.exe”保存路径，再启动后台。GaussView、formchk、cubegen 不替代 Gaussian 计算主程序。文件存在仅说明被探测到，不等于许可证有效或计算验证通过。

包含安装介质的部署包可能超过 350 MB。厂商安装器如果依赖额外文件，应使用原始完整介质单独安装；当前附带服务针对独立 EXE 安装程序。
